# 離乳食レシピビューア (Baby Food Recipe Viewer)

離乳食の初期・中期・後期における調理手順やボタン操作をシンプルに確認・管理できる個人用Webアプリケーションです。

---

## 🌟 主な機能
- **離乳食時期別の切り替え**: 初期 / 中期 / 後期 タブによるレシピ表示
- **調理ボタンガイド**: レコルト等の調理器具のボタン操作（例: `potage & paste`）を表示
- **食べた実績チェック**: 食べたことのあるレシピのチェック・記録（ブラウザ保存）
- **自由メモ**: 個別のメモやアレンジの保存
- **カテゴリフィルター & 検索**: 炭水化物・野菜・タンパク質ごとの絞り込み

---

## 🛠 技術スタック
- React 18
- Vite
- Tailwind CSS
- Lucide React (Icons)
